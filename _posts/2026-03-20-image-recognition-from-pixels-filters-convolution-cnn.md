很多人第一次接觸圖像識別時，常常會有兩個誤解。

- 第一個誤解是：電腦好像是直接「看懂」圖片。
- 第二個誤解是：`CNN` 好像只是一個新的模型縮寫。

但如果把事情拆開來看，圖像識別其實有兩條主線。

- 第一條線是：圖片會先被表示成數字矩陣，再透過卷積與濾波把局部特徵顯性化。
- 第二條線是：`CNN` 會把這種局部特徵抽取能力系統化，最後用在分類與辨識任務上。

這篇文章我想做的事情很單純：先把像素、濾波、卷積、`CNN` 這條路講清楚，再用兩個實作把概念落地。

- 練習一：先不碰模型，只用一張本地圖片做濾波與邊緣偵測
- 練習二：在 `MNIST` 上比較 `MLP` 和 `CNN`

# 1. 電腦眼中的圖片不是「圖」，而是數字矩陣

如果你把一張照片放大到很大，最後你看到的就不再是連續的畫面，而是一格一格的色塊。  
對電腦來說，這些色塊就是 **pixel（像素）**。

而一張圖片能被電腦處理，關鍵不是它有沒有意義，而是它能不能被表示成一堆數字。

- `resolution`（解析度）指的是圖片有多少列、多少行像素
- 灰階圖通常可以用 `0` 到 `255` 表示亮度
- 彩色圖通常會拆成 `R`、`G`、`B` 三個通道，各自用數值表示強度

如果我要先講這一節最重要的一句話，我會這樣說：

**圖像識別的第一步，不是理解語意，而是先把圖片轉成電腦可以運算的矩陣。**

![圖片如何被表示成矩陣與 RGB 通道](/assets/images/260320/image-matrix-rgb.svg)

_圖：肉眼看到的是圖片；電腦真正操作的是像素格子與 RGB 通道數值。_

用最白話的方式理解：

- 灰階圖像：每個像素只要一個數字
- 彩色圖像：每個像素通常要三個數字
- 一整張圖：就是很多像素排成的矩陣

這也是為什麼後面談卷積時，我們其實是在談「一個小矩陣怎麼在另一個大矩陣上滑動並做運算」。

# 2. 卷積與空間濾波：圖像前處理到底在做什麼

當圖片已經變成矩陣後，下一個問題就變成：  
**要怎麼把對辨識有幫助的局部特徵先拉出來？**

這時候就會遇到 **convolution（卷積）** 和 **spatial filtering（空間濾波）**。

我自己最習慣的理解方式是：拿一個小小的 `kernel`（卷積核 / 濾波器），在圖片上一步一步滑動；每到一個位置，就把局部區塊和這個小矩陣做一次乘積加總，得到新的輸出值。

如果這個小矩陣是人手先定義好的，它就比較像傳統影像處理裡的濾波器。  
如果這個小矩陣是模型在訓練中自己學出來的，它就會變成 `CNN` 裡的卷積層權重。

## 2.1 幾種最常見的濾波器

這一章課本裡講到的幾種濾波器，我會把它們壓成下面四個重點：

- **平均濾波（average filter）**：把局部區域做平均，效果通常是平滑、模糊、降低細碎雜訊
- **權重平均濾波（weighted average filter）**：中心附近給比較高權重，通常比單純平均更接近原圖
- **中值濾波（median filter）**：不是做乘積加總，而是取局部區塊的中位數，對孤立雜訊特別有感
- **Sobel filter**：用兩個方向的梯度去抓亮度變化，讓邊緣更明顯

如果我再把這一段收成一句話：

**卷積的價值，不只是算出一張新圖片，而是把「哪些局部模式值得注意」這件事先做出來。**

## 2.2 為什麼這件事很重要

這裡真正重要的不是你會不會手算每一步，而是你要開始有一個直覺：

- 平滑濾波會壓掉高頻細節
- 邊緣偵測會把輪廓和亮度變化拉出來
- 不同濾波器，本質上就是在問圖片不同的局部問題

而 `CNN` 做的事情，就是把這種「問局部問題」的能力，從手工設計改成讓模型自己學。

# 3. 練習一：先不碰模型，用一張本地圖片做濾波與邊緣偵測

我覺得這是今天最值得先做的練習。  
原因很簡單：很多人一上來就急著跑 `CNN`，反而沒有先建立「卷積真的會怎麼改變一張圖」的感覺。

我在 repo 裡補了一個新的腳本 `image_filter_demo.py`，它會做四件事：

- 把本地圖片轉成灰階
- 輸出平均濾波結果
- 輸出權重平均濾波結果
- 輸出中值濾波與 `Sobel` 邊緣偵測結果

你可以這樣跑：

```powershell
python image_filter_demo.py --input path\to\your-image.png --output-dir .\outputs
```

如果你想直接用我這篇文章的示範圖，我這次用的是 `course` 裡的：

```text
course/Teaching-Resource/ai/Neural-Network/demo_assets/image_filters/image-filter-demo-source.png
```

我實際生成的比較圖如下：

![同一張圖片的濾波與邊緣偵測結果](/assets/images/260320/image-filter-demo-grid.png)

_圖：同一張本地圖片經過 average、weighted average、median、sobel 處理後的差異。_

這張圖最值得注意的地方，我會這樣看：

- `average` 最明顯地把整張圖變平滑，但也最容易把細節一起洗掉
- `weighted average` 仍然有平滑效果，但中心資訊保留得比單純平均更好
- `median` 對局部突兀雜訊通常更不敏感，而且邊緣不一定會像平均濾波那樣被抹得那麼重
- `sobel` 幾乎不再保留原本的灰階外觀，而是把數字、車殼輪廓和邊界亮出來

如果你要把這個練習當成真正的觀察題，可以先回答這四題：

1. 哪一種濾波最明顯地讓圖片變平滑？
2. 哪一種濾波對雜訊更不敏感？
3. `Sobel` 把哪些邊緣強調出來？
4. 為什麼這些操作能視為後續模型抽特徵的前身？

# 4. 為什麼圖像識別後來走向 CNN

前一節的濾波器都是人手定義的。  
但如果今天你要辨識的是貓、狗、車牌、零件、道路標線，你不可能每一種情況都自己手刻一組最佳濾波器。

這就是 `CNN`（Convolutional Neural Network，卷積神經網路）出現的關鍵背景：

**前面的濾波器概念沒有消失，而是變成由模型自己學。**

我自己會把 `CNN` 的核心拆成五個零件：

- **卷積層（convolution layer）**：從局部區域學邊緣、角點、紋理、局部形狀
- **池化層（pooling layer）**：保留主要反應、壓縮空間尺寸、降低計算量
- **全連接層（fully-connected layer）**：把抽出的特徵整合成最後分類分數
- **`ReLU`**：提供非線性，讓模型不只是在做線性組合
- **`Softmax`**：把最後輸出轉成各類別機率

這裡最重要的一句話是：

**`CNN` 不是因為名字新才重要，而是因為它比單純全連接網路更符合影像本身的空間結構。**

![CNN 擅長從局部模式逐層組成整體特徵](/assets/images/260317/cnn-local-patterns.svg)

_圖：`CNN` 的強項是先抓局部模式，再把局部特徵一路組合成更抽象的表示。_

## 4.1 為什麼不是直接用全連接層就好

如果你把一張圖直接攤平成很長的一維向量，再丟進 `MLP`（多層感知器），模型不是完全不能做分類。  
但這種做法有一個很大的問題：它會把原本的空間鄰近關係沖淡掉。

對影像來說，下面這些事很重要：

- 左上角有沒有一條邊
- 兩條邊有沒有形成一個角
- 某個紋理是不是重複出現
- 某個局部形狀是不是在不同位置都可能出現

`CNN` 會把這些局部模式當成第一級問題來處理。  
這也是它在影像任務上長期有效的原因。

## 4.2 AlexNet 為什麼常被提到

如果你回頭看深度學習的歷史，`AlexNet` 會一直被提到，因為它在 2012 年的 `ImageNet Large Scale Visual Recognition Challenge` 裡展示了卷積神經網路的威力。

我不會把 `AlexNet` 當成現在最實用的模型，但它是一個非常重要的里程碑：  
它讓大家看到，當資料、算力和卷積架構結合起來時，影像辨識可以跨過一個很大的門檻。

# 5. 模型訓練不是只有架構，還有資料切分與過擬合

學到這裡，很多人會開始把全部焦點放在模型架構。  
但如果只看架構，你很快就會漏掉另一半問題：資料怎麼切、模型有沒有記住訓練集而不是學會泛化。

## 5.1 訓練集、驗證集、測試集在做什麼

我自己會這樣記：

- **訓練集（training set）**：拿來學參數
- **驗證集（validation set）**：拿來調整設計與觀察模型方向
- **測試集（test set）**：最後才用來看泛化結果

如果你把這三個角色混在一起，最後很容易高估模型實力。

## 5.2 ImageNet 為什麼重要

`ImageNet` 之所以常被拿來講，不只是因為它大，而是因為它把「大量、多類別、標註過的影像資料」這件事帶進了深度學習影像研究的主舞台。

如果要把這一節最重要的一句話講清楚，我會這樣說：

**圖像識別的效果，不只取決於模型長什麼樣，也取決於你有沒有足夠多樣、足夠乾淨、切分合理的資料。**

## 5.3 過擬合怎麼理解

**overfitting（過擬合）** 指的是模型在訓練資料上學得很好，但一到新資料就明顯失真。  
最常見的訊號就是：

- `train_acc` 很高
- `test_acc` 或 `validation_acc` 上不去

常見對策有兩類：

- **資料增強（data augmentation）**：像旋轉、平移、裁切、亮度改動，讓同一張圖長出更多變體
- **`dropout`**：訓練時暫時關掉部分神經元，降低模型過度依賴少數路徑的風險

# 6. 圖像識別已經在哪些地方出現

如果只把圖像識別想成「辨識貓狗」，其實會看太窄。  
同一套抽特徵再做分類或搜尋的思路，已經反覆出現在很多產品裡。

## 6.1 自動相簿整理

手機相簿會自動把人臉、地點、活動或某些常見物件整理起來。  
這背後依靠的不是單一魔法，而是一連串表示、特徵抽取、分類與檢索能力。

## 6.2 圖片網與影片網

平台要做內容分類、搜尋、封面推薦、違規偵測，幾乎都離不開影像理解。  
即使不直接顯示給使用者看，後台也會用這些能力降低人工標記成本。

## 6.3 互動式行銷與使用者輪廓

當圖片與 `UGC`（user-generated content，使用者生成內容）被大量上傳後，平台就能從視覺內容裡補充使用者偏好訊號。  
這也是為什麼圖像識別不只在研究領域重要，在產品、廣告與推薦系統裡也很常出現。

# 7. 練習二：在 MNIST 上比較 MLP 和 CNN

如果前面的濾波練習是在建立直覺，那這個練習就是把直覺往模型推進一步。

我在 repo 裡已經有兩個現成腳本：

- `nn_example.py`：`MNIST` 上的全連接分類
- `cnn_example.py`：`MNIST` 上的小型卷積分類

你可以直接在 `Neural-Network` 目錄跑：

```powershell
python nn_example.py --epochs 1
python cnn_example.py --epochs 1
```

我在本機 CPU 上跑一次，得到的是：

- `MLP`：`train_acc=0.6371`、`test_acc=0.7622`
- `CNN`：`train_acc=0.5420`、`test_acc=0.7477`

如果你只看這組 1 epoch 的結果，會發現差距其實很近，甚至這次 `MLP` 稍微高一點。  
這件事反而很值得初學者注意：

**結構優勢通常不是在超小資料量、超短訓練下立刻展開，而是當訓練多跑幾輪後，`CNN` 更容易把影像的空間特徵用起來。**

我把同樣的兩個腳本拉到 `3` 個 epoch，再跑一次，結果就比較接近很多人熟悉的現象：

- `MLP`：`test_acc=0.8729`
- `CNN`：`test_acc=0.8882`

換句話說，如果你今天只跑 `--epochs 1`，重點不是立刻比出勝負，而是先看懂它們處理圖片的方式差在哪裡。

## 7.1 這個練習真正要你看到什麼

我覺得這個比較最有價值的地方，不是分數本身，而是你會開始看到：

- `MLP` 一開始就把圖片攤平成長向量
- `CNN` 會先保留二維結構，讓卷積層去抓局部模式
- 池化層會把主要特徵留下來，同時壓縮尺寸
- 訓練跑開之後，`CNN` 往往更能把這些空間關係轉成分類優勢

如果你想讓差距更穩定，可以直接試下面這組延伸指令：

```powershell
python nn_example.py --epochs 3
python cnn_example.py --epochs 3
```

你可以先回答這四題：

1. `MLP` 和 `CNN` 對輸入圖片的處理差在哪裡？
2. 池化層在這個例子裡幫了什麼忙？
3. 為什麼 `CNN` 比較能保留局部空間資訊？

# 8. 結語：圖像識別不是一個名詞，而是一條完整流程

如果要把今天這篇再壓成一句話，我會這樣說：

**圖像識別的核心，不是讓電腦「看到」圖片，而是讓模型從像素矩陣裡逐層學出對辨識有用的特徵。**

所以這條路其實是連在一起的：

- 圖片先變成矩陣
- 卷積與濾波先讓你看見局部特徵可以怎麼被強調
- `CNN` 再把這種特徵抽取能力變成可學習的模型
- 最後才落到分類、搜尋、推薦或產品應用

如果你今天只想做一件事，我會建議你先把兩個練習都跑過：

- 先跑 `image_filter_demo.py`，建立對卷積與特徵的視覺直覺
- 再跑 `nn_example.py` 和 `cnn_example.py`，理解為什麼影像任務常常會走向 `CNN`

如果接下來你還想往更前沿的方向看，再去看 `Stanford Vision`、`MIT CSAIL`、`DeepMind` 這些研究與團隊也不遲。  
但在那之前，我覺得把今天這條「像素 -> 卷積 -> `CNN` -> 訓練 -> 應用」的主線先走順，會更重要。
