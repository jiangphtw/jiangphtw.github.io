許多人初次接觸影像辨識時，常有兩項誤解。

- 認為電腦能直接理解圖片內容
- 認為 `CNN` 只是一個新的模型縮寫

若拆解整個流程，影像辨識其實包含兩條主線。

- 圖片會先表示為數值矩陣，再透過卷積與濾波凸顯局部特徵
- `CNN` 會將這種局部特徵擷取能力系統化，最後用於分類與辨識任務

本文會先說明像素、濾波、卷積與 `CNN` 之間的關係，再透過兩個實作練習驗證概念。

- 練習一：暫不使用模型，僅以一張本機圖片進行濾波與邊緣偵測
- 練習二：在 `MNIST` 上比較 `MLP` 和 `CNN`

# 1. 電腦處理的不是「圖片」，而是數值矩陣

將一張照片持續放大後，看到的將不再是連續畫面，而是一格一格的色塊。
對電腦而言，這些色塊就是 **pixel（像素）**。

電腦能否處理一張圖片，關鍵不在於圖片是否具有意義，而在於它能否表示為一組數值。

- `resolution`（解析度）是指圖片包含多少列與多少欄像素
- 灰階圖通常可以用 `0` 到 `255` 表示亮度
- 彩色圖通常會拆成 `R`、`G`、`B` 三個通道，各自用數值表示強度

本節最重要的概念是：

**影像辨識的第一步不是理解語意，而是將圖片轉換成電腦可運算的矩陣。**

![圖片如何被表示成矩陣與 RGB 通道](/assets/images/260320/image-matrix-rgb.svg)

_圖：人眼看到的是圖片，電腦實際處理的則是像素網格與 RGB 通道數值。_

以簡單方式說明：

- 灰階影像：每個像素只需要一個數值
- 彩色影像：每個像素通常需要三個數值
- 完整影像：由大量像素排列成矩陣

因此，後續討論卷積時，實際上是在說明「一個小矩陣如何在另一個大矩陣上滑動並進行運算」。

# 2. 卷積與空間濾波：影像前處理在做什麼

當圖片轉換成矩陣後，下一個問題是：
**如何先擷取有助於辨識的局部特徵？**

這時就需要使用 **convolution（卷積）** 與 **spatial filtering（空間濾波）**。

可以將其理解為：讓一個小型 `kernel`（卷積核／濾波器）在圖片上逐步滑動；每移至一個位置，就將局部區域與這個小矩陣對應相乘並加總，產生新的輸出值。

如果這個小矩陣由人工預先定義，它就相當於傳統影像處理中的濾波器。
如果這個小矩陣由模型在訓練過程中學得，它就會成為 `CNN` 的卷積層權重。

## 2.1 幾種最常見的濾波器

本章提到的濾波器可整理為以下四類：

- **平均濾波（average filter）**：把局部區域做平均，效果通常是平滑、模糊、降低細碎雜訊
- **加權平均濾波（weighted average filter）**：給予中心附近較高權重，結果通常比單純平均更接近原圖
- **中值濾波（median filter）**：不進行乘積加總，而是取局部區域的中位數，特別適合處理孤立雜訊
- **Sobel 濾波器**：使用兩個方向的梯度偵測亮度變化，使邊緣更明顯

這段內容可以總結為一句話：

**卷積的價值不只在於產生新圖片，還在於凸顯值得關注的局部模式。**

## 2.2 為何這項技術很重要

這裡的重點不是能否手動計算每個步驟，而是建立以下直觀理解：

- 平滑濾波會抑制高頻細節
- 邊緣偵測會凸顯輪廓與亮度變化
- 不同濾波器會針對圖片中的不同局部特徵進行運算

`CNN` 則將這種局部特徵分析能力，從人工設計改為由模型自行學習。

_圖：同一張本機圖片經過平均、加權平均、中值與 Sobel 濾波後的差異。_

這張圖可觀察到以下差異：

- `average` 能最明顯地平滑整張圖片，但也最容易一併移除細節
- `weighted average` 仍有平滑效果，但比單純平均保留更多中心資訊
- `median` 通常較不受局部突發雜訊影響，且邊緣不會像經過平均濾波後那樣明顯模糊
- `sobel` 幾乎不保留原本的灰階外觀，而會凸顯數字、車殼輪廓與邊界

2. 哪一種濾波對雜訊更不敏感？
3. `Sobel` 把哪些邊緣強調出來？
4. 為什麼這些操作能視為後續模型抽特徵的前身？

# 4. 影像辨識為何採用 CNN

前一節的濾波器都是由人工定義。
但若要辨識貓、狗、車牌、零件或道路標線，不可能針對每種情況逐一手動設計最佳濾波器。

這正是 `CNN`（Convolutional Neural Network，卷積神經網路）出現的重要背景：

**濾波器的概念並未消失，而是改由模型自行學習。**

`CNN` 的核心可拆解為五個組成部分：

- **卷積層（convolution layer）**：從局部區域學邊緣、角點、紋理、局部形狀
- **池化層（pooling layer）**：保留主要反應、縮小空間尺寸並降低運算量
- **全連接層（fully connected layer）**：將擷取的特徵整合成最終分類分數
- **`ReLU`**：提供非線性，讓模型不只是在做線性組合
- **`Softmax`**：把最後輸出轉成各類別機率

其中最重要的觀念是：

**`CNN` 的重要性不在於名稱新穎，而在於它比單純的全連接網路更符合影像本身的空間結構。**

![CNN 擅長從局部模式逐層組成整體特徵](/assets/images/260317/cnn-local-patterns.svg)

_圖：`CNN` 的強項是先擷取局部模式，再逐層將局部特徵組合成更抽象的表示。_

## 4.1 為何不直接使用全連接層

若將一張影像直接攤平成很長的一維向量，再送入 `MLP`（多層感知器），模型仍可進行分類。
但這種做法有一項明顯問題：它會弱化原本的空間鄰近關係。

對影像而言，下列空間關係十分重要：

- 左上角有沒有一條邊
- 兩條邊有沒有形成一個角
- 某個紋理是不是重複出現
- 某個局部形狀是不是在不同位置都可能出現

`CNN` 會優先處理這些局部模式。
這也是它長期適用於影像任務的原因。

## 4.2 AlexNet 為何經常被提及

回顧深度學習的發展歷史，`AlexNet` 經常被提及，因為它在 2012 年的 `ImageNet Large Scale Visual Recognition Challenge` 中展現了卷積神經網路的能力。

`AlexNet` 雖不是現今最實用的模型，卻是非常重要的里程碑。
它證明資料、運算能力與卷積架構結合後，能大幅提升影像辨識效果。

# 5. 模型訓練不只涉及架構，還包括資料切分與過度擬合

學到這裡，許多人會將所有注意力放在模型架構上。
但若只關注架構，就會忽略另一半問題：如何切分資料，以及模型究竟只是記住訓練集，還是真正具備泛化能力。

## 5.1 訓練集、驗證集與測試集的用途

三種資料集的用途如下：

- **訓練集（training set）**：拿來學參數
- **驗證集（validation set）**：拿來調整設計與觀察模型方向
- **測試集（test set）**：在最後階段評估泛化表現

如果混用這三種資料集，最終很容易高估模型效能。

## 5.2 ImageNet 為何重要

`ImageNet` 經常被提及，不只是因為資料規模龐大，還因為它讓大量、涵蓋多種類別且已標註的影像資料，成為深度學習影像研究的重要基礎。

本節最重要的觀念是：

**影像辨識效果不只取決於模型架構，也取決於資料是否足夠多樣、乾淨且切分合理。**

## 5.3 如何理解過度擬合

**overfitting（過度擬合）** 是指模型在訓練資料上表現良好，但面對新資料時表現明顯下降。
最常見的現象是：

- `train_acc` 很高
- `test_acc` 或 `validation_acc` 無法提升

常見對策有兩類：

- **資料增強（data augmentation）**：透過旋轉、平移、裁切或改變亮度，從同一張圖片產生更多變體
- **`dropout`**：在訓練時暫時停用部分神經元，降低模型過度依賴少數路徑的風險

# 6. 影像辨識的常見應用

如果只將影像辨識理解為「辨識貓狗」，範圍就過於狹窄。
先擷取特徵，再進行分類或搜尋的技術，已廣泛應用於各類產品。

## 6.1 自動相簿整理

手機相簿會自動整理人臉、地點、活動或常見物件。
這項功能並非來自單一技術，而是結合表示學習、特徵擷取、分類與檢索等能力。

## 6.2 圖片與影片平台

平台進行內容分類、搜尋、封面推薦與違規偵測時，幾乎都需要影像理解技術。
即使相關結果不直接呈現給使用者，後端系統也會運用這些能力降低人工標註成本。

## 6.3 互動式行銷與使用者輪廓

當大量圖片與 `UGC`（user-generated content，使用者生成內容）上傳至平台後，平台便能從視覺內容中取得更多使用者偏好訊號。
因此，影像辨識不只對研究領域重要，也廣泛應用於產品、廣告及推薦系統。

# 7. 練習二：在 MNIST 上比較 MLP 與 CNN

前面的濾波練習旨在建立直觀認識，這項練習則進一步將概念延伸至模型。

儲存庫中已有兩個可直接使用的腳本：

- `nn_example.py`：`MNIST` 上的全連接分類
- `cnn_example.py`：`MNIST` 上的小型卷積分類

可直接在 `Neural-Network` 目錄中執行：

```powershell
python nn_example.py --epochs 1
python cnn_example.py --epochs 1
```

在本機 CPU 上執行一次後，得到以下結果：

- `MLP`：`train_acc=0.6371`、`test_acc=0.7622`
- `CNN`：`train_acc=0.5420`、`test_acc=0.7477`

如果只看這組 `1 epoch` 的結果，兩者差距其實很小，而且本次 `MLP` 的數值略高。
初學者應特別注意：

**模型的結構優勢通常不會在資料量極少、訓練時間極短時立即顯現；增加訓練輪數後，`CNN` 通常更能利用影像的空間特徵。**

將同樣的兩個腳本調整為 `3 epochs` 並再次執行後，結果便更接近常見情況：

- `MLP`：`test_acc=0.8729`
- `CNN`：`test_acc=0.8882`

換句話說，如果只執行 `--epochs 1`，重點不是立即判定哪個模型較好，而是先理解兩者處理圖片的方式有何差異。

## 7.1 這項練習的觀察重點

這項比較最有價值的部分不是分數本身，而是下列差異：

- `MLP` 一開始就把圖片攤平成長向量
- `CNN` 會先保留二維結構，再由卷積層擷取局部模式
- 池化層會把主要特徵留下來，同時壓縮尺寸
- 經過較充分的訓練後，`CNN` 往往更能將這些空間關係轉化為分類優勢

若要更穩定地觀察差距，可以嘗試以下延伸指令：

```powershell
python nn_example.py --epochs 3
python cnn_example.py --epochs 3
```

# 8. 結語：影像辨識是一套完整流程

本文可以總結為一句話：

**影像辨識的核心不是讓電腦「看到」圖片，而是讓模型從像素矩陣中逐層學得有助於辨識的特徵。**

整套流程彼此相連：

- 圖片先變成矩陣
- 卷積與濾波先呈現如何凸顯局部特徵
- `CNN` 再將這種特徵擷取能力轉化為可學習的模型
- 最後才落到分類、搜尋、推薦或產品應用

建議先完整執行這兩項練習：

- 先執行 `image_filter_demo.py`，建立對卷積與特徵的視覺直觀認識
- 再執行 `nn_example.py` 與 `cnn_example.py`，理解影像任務為何經常採用 `CNN`

若想進一步了解前沿研究，可以再參考 `Stanford Vision`、`MIT CSAIL` 與 `DeepMind` 等研究團隊的成果。
但在此之前，更重要的是先掌握「像素 → 卷積 →`CNN`→ 訓練 → 應用」這條主線。
