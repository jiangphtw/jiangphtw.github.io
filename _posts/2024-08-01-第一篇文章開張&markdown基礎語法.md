今天終於下定決心，開始用部落格記錄生活。第一篇文章就從 Markdown 基礎語法談起吧！我在研究所時才接觸 Markdown；它簡單易學，也能運用在許多平台。接下來就一起看看常用的基本語法。

# Markdown 教學：從基礎到進階

Markdown 是一種輕量級的標記語言，適合快速撰寫具有格式的文件。本文將介紹從基礎到進階的 Markdown 語法，幫助你熟悉並掌握這項工具。

## 1. 基礎語法

### 1.1 標題
使用 `#` 符號來建立標題，`#` 的數量代表標題的層級。

```markdown
# 標題 1
## 標題 2
### 標題 3
```

### 1.2 段落與換行
段落之間空一行來分隔。若要換行，可以在行末添加兩個空格，然後按下 Enter 鍵。

```markdown
這是一個段落。

這是另一個段落。
```

### 1.3 粗體與斜體
使用 `**` 或 `__` 包圍文字來表示粗體，使用 `*` 或 `_` 表示斜體。

```markdown
**這是粗體字**
*這是斜體字*
```

### 1.4 列表
有序列表使用數字加點號，如 `1.`；無序列表使用 `-` 或 `*`。

```markdown
1. 第一項
2. 第二項

- 無序項目
* 另一個無序項目
```

### 1.5 超連結
使用 `[連結文字](URL)` 來建立連結。

```markdown
[點擊這裡訪問 Google](https://www.google.com)
```

### 1.6 圖片
使用 `![替代文字](圖片 URL)` 來插入圖片。

```markdown
![Markdown Logo](https://markdown-here.com/img/icon256.png)
```

## 2. 進階語法

### 2.1 引用
使用 `>` 來建立引用，多層引用則可以使用多個 `>`。

```markdown
> 這是一個引用。
>> 這是巢狀的引用。
```

### 2.2 程式碼區塊
使用反引號（\`）來標示行內程式碼，用三個反引號來標示多行程式碼區塊。

```markdown
這是一段 \`行內程式碼\`。

\`\`\`
這是一個程式碼區塊：
\`\`\`
```

### 2.3 表格
使用 `|` 來建立表格，並使用 `:` 來控制對齊方式。

```markdown
| 項目   | 描述       |
|--------|------------|
| Markdown | 輕量標記語言 |
| HTML     | 網頁標記語言 |

| 左對齊 | 中間對齊 | 右對齊 |
|:-------|:-------:|-------:|
| 項目一 |  項目二  |  項目三 |
```

### 2.4 任務列表
使用 `- [ ]` 建立待辦事項列表，使用 `- [x]` 表示已完成的項目。

```markdown
- [ ] 待辦事項 1
- [x] 已完成事項 2
```

### 2.5 分隔線
使用三個或更多的 `-`、`*` 或 `_` 建立分隔線。

```markdown
---

***

___
```

### 2.6 注腳
使用 `[^1]` 建立注腳，然後在文件底部添加注腳內容。

```markdown
這是一個帶有注腳的句子[^1]。

[^1]: 這是注腳的內容。
```

## 3. 進階技巧

### 3.1 巢狀列表
可以在列表中加入其他列表；只要將子項目縮排，即可建立巢狀列表。

```markdown
1. 項目一
   - 子項目一
   - 子項目二
2. 項目二
   1. 子項目一
   2. 子項目二
```

### 3.2 使用 HTML 標籤
在 Markdown 文件中，可以直接使用 HTML 標籤，補充 Markdown 本身不易呈現的格式。

```markdown
這是一段使用 <strong>HTML 標籤</strong>的文字。
```

### 3.3 使用 HTML 調整圖片尺寸
若要控制圖片大小，可以使用 HTML 標籤設定寬度與高度。

```markdown
<img src="https://markdown-here.com/img/icon256.png" alt="Markdown Logo" width="100" height="100">
```

## 結語

Markdown 是一種簡潔且靈活的標記語言，能幫助你輕鬆建立具有格式的文字。無論是撰寫部落格、技術文件，還是整理筆記，掌握 Markdown 語法都能大幅提升工作效率。
