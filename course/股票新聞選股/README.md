# 股海判讀學

把工作區內的台股操作筆記重整為 5 階段、9 單元的本地線上課程，並加入重大事件對美股與台股的比較章節。

## 課程內容

- 財報體質與獲利品質
- 估值、殖利率與常見陷阱
- K 線、支撐壓力、均線與 RSI
- 公開資訊觀測站與新聞查證
- 題材生命週期與利多鈍化
- 股票期貨、保證金與槓桿風險
- 融券放空、軋空與失效條件
- 除權息、景氣循環與決策備忘錄
- 網路泡沫、SARS、金融海嘯、比特幣、新冠、戰爭與 AI 浪潮的美台股影響

每個單元包含中文與英文影片、學習目標、完整文字教學文章、案例、三階段練習、官方延伸閱讀與可交付成果。第 9 單元另含十項事件比較板與逐事件圖表，並標示事件日、峰谷、年度或事件窗等不同數字口徑。

## 本地開啟

```powershell
npm install
npm run dev
```

終端會顯示本地網址。學習進度、練習勾選與字級偏好只保存在目前瀏覽器。

## 檢查

```powershell
npm run lint
npm test
```

正式建置會輸出至 `out/`，主站的 GitHub Actions 會把它發布到 `/course/stock-decision/`。若在含非 ASCII 字元的 Windows 路徑執行時異常，可從指向本專案的純 ASCII 路徑 junction 執行；不需移動或複製專案。

## 可選討論區

如需啟用 giscus，複製 `.env.example` 為 `.env.local`，填入四個公開設定值後重新啟動本地網站。

## 使用聲明

本課程為教育與研究用途，不構成投資建議。教學影片權利屬原創作者；本站只提供策展連結與原創學習引導。課程是原筆記的主題式重構，不是逐頁重製；個股案例僅選代表性內容。交易制度與保證金可能調整，實際操作前應查閱主管機關與交易所最新公告。

課程與原筆記的逐章比較、制度校正與省略範圍，請見 [COURSE_NOTE_VALIDATION.md](./COURSE_NOTE_VALIDATION.md)。
